# -_-_-_- Ude@Book -_-_-_-

**"Amigos para siempre, Udea@Book"**  es una aplicación de red social desarrollado en C++ utilizando Qt Creator. Permite gestionar usuarios, amistades, mensajes, solicitudes de amistad, sugerencias de nuevos amigos y álbumes de fotos.

---

## _-_-_-_ Funcionalidades _-_-_-_

* Registro y autenticación de los usuarios.
* Gestión de amistades.
* Gestión de mensajes.
* Consulta de sugerencias de amistad según cantidad de amigos en común.
* Gestión de álbumes de fotos con diferentes tipos de privacidad.
* Almacenamiento y carga de datos mediante archivos de texto.
